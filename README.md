# p4-travel-agency-db
Travel agency booking system with SQLite database. Manages clients, tours, bookings, payments, and hotels.
Система управління турагентством

SQLite-базована система управління базою даних для турагентства. Цей проект демонструє дизайн бази даних, маніпуляцію даними та SQL-запити для управління клієнтами, турами, бронюваннями, платежами та готелями.

Описання:

Це проект Практичного завдання 4, який реалізує повноцінну систему управління турагентством:

Управління клієнтами

Каталог турів з описами та цінами

Система бронювання зі стеженням статусу

Обробка платежів

Інформація про готелі та їх рейтинги

Країни та вимоги щодо віз

Зв'язки "багато-до-багатьох" між сутностями

  Структура бази даних:
  
Таблиці

client - Інформація про клієнтів

id_client (INTEGER PRIMARY KEY)
first_name, last_name (TEXT) - ім'я та прізвище
email, phone_number (TEXT) - електронна пошта та телефон
passport_information (TEXT) - паспортні дані

tour - Доступні тури

id_tour (INTEGER PRIMARY KEY)
title, description (TEXT) - назва та опис
duration (INTEGER) - тривалість в годинах
base_price (REAL) - базова ціна

booking - Бронювання клієнтів

id_booking (INTEGER PRIMARY KEY)
status (TEXT - 'pending', 'confirmed', 'cancelled') - статус
total_price (REAL) - загальна ціна
booking_date (TEXT) - дата бронювання
tour_id, client_id (FOREIGN KEYS) - посилання на тури та клієнтів

payment - Записи про платежі

id_payment (INTEGER PRIMARY KEY)
payment_method (TEXT - 'card', 'cash', 'transfer') - спосіб оплати
amount (REAL) - сума
payment_date (TEXT) - дата платежу
booking_id (FOREIGN KEY) - посилання на бронювання

hotel - Готелі для проживання

id_hotel (INTEGER PRIMARY KEY)
name, address (TEXT) - назва та адреса
star_rating (TEXT - '1' до '5') - рейтинг зірками
contact_info (TEXT) - контактна інформація

country - Країни

id_country (INTEGER PRIMARY KEY)
name (TEXT) - назва
visa_required (BOOLEAN) - чи потрібна віза

tour_country - Зв'язок багато-до-багатьох
Пов'язує тури з країнами

tour_hotel - Зв'язок багато-до-багатьох
Пов'язує тури з готелями

  Як користуватися:
1. Створення та заповнення бази даних

Запустіть основний скрипт для створення всіх таблиць і вставлення прикладних даних:

bashpython python_solution.py

Це буде:

Створить файл travel_agency.db SQLite бази даних

Створить усі необхідні таблиці з обмеженнями

Вставить прикладні дані (3 клієнти, 3 тури, 3 готелі та ін.)

Виконає SELECT запити для виведення даних

Виконає UPDATE операції

Виведе результати після оновлення

2. Операції з базою даних

Скрипт виконує такі операції:

CREATE (Створення таблиць)

Створює 8 таблиць з правильними зв'язками

Визначає обмеження (CHECK, FOREIGN KEY)

Використовує AUTO_INCREMENT для допоміжних таблиць

INSERT (Вставлення прикладних даних):

Клієнти: Марина, Віктор, Наталія

Тури: Скарби Італії, Іспанські канікули, Французька класика

Готелі: Bella Roma (3★), Costa del Sol (4★), Eiffel View (5★)

Країни: Італія, Іспанія, Франція

SELECT (Запити на вибірку):

Підтверджені бронювання з іменами клієнтів і названиями турів

Показує всі підтверджені бронювання з інформацією про клієнта та тур

Тури з готелями на 4 зірки

Виводить тури, пов'язані з готелями з рейтингом 4 зірки

UPDATE (Оновлення даних):

Змінює статус бронювання з 'pending' на 'confirmed' (id_booking = 1)

Змінює рейтинг готелю з 4 зірок на 5 зірок

Перевірка:

Запускає ті ж самі SELECT запити після UPDATE

Перевіряє, що зміни були застосовані правильно

Показує, що бронювання та рейтинги готелів були змінені
